# 大富翁 · 地产小镇 — 设计规格

日期：2025-09-09
状态：已确认（方向 A + 全功能）

## 1. 目标

一个可以直接打开就能玩的网页版大富翁（Monopoly 变体），手机竖屏为主，桌面和平板自适应。
单人对抗 3 个 AI，规则完整度接近经典大富翁。

## 2. 视觉方向：3D 手游风（v3）

| 角色 | 取值 |
|---|---|
| 天幕 | `#1B4E96` → `#5FA8E4` → `#9FD8F7` |
| 棋盘框 | `#FFD98A` → `#E09A33`（立体边 `#A9661A`） |
| 棋盘面 | `#FFFDF4` → `#FFEFC9` |
| 金 / 粉 / 绿 / 蓝 / 紫 | `#FFC93C` / `#FF5C8A` / `#4CD964` / `#35C1F0` / `#A96BFF` |
| 文字 | `#1B2A4A` 墨蓝 / `#55668A` 次级 |

- 立体结构：`inset 顶部高光 + inset 底部暗边 + 实心立体边 0 5px 0 + 投影`，按下 `translateY(5px)` 落到立体边上。
- 棋盘框用双层渐变（`padding-box` 奶油面 / `border-box` 琥珀框）+ `0 9px 0` 厚度。
- 字体 800–900 圆体；关键文字用多层 `text-shadow` 做深色描边。
- 分组色：A 粉、B 橙、C 绿、D 蓝、E 紫；车站灰蓝、公用金色。

### 签名元素
**金币飞入 + 印章盖章**：收钱时金币从格子沿抛物线飞进玩家卡片（`@keyframes coinFly`）；买地时金色印章弹跳盖下并撒 14 片彩带；付租金/缴税时 `.app` 震屏 420ms。

### 动效清单
棋盘弹入 · 格子逐个弹出 · 骰子翻滚落定 · 棋子逐格挤压跳跃 · 金币飞入 · 震屏 · 卡片轻晃 · 按钮下沉回弹 · 弹层弹簧滑入 · 地契 3D 翻转 · 环境太阳/云朵。全部在 `prefers-reduced-motion` 下关闭。

### 主题备份
上一版糖果风样式保存在 `themes/theme-candy.css`，替换 `styles.css` 即可回滚。

## 3. 布局

手机竖屏（390×844）：

```
┌──────────────────────────┐
│ 大富翁 · 地产小镇      ♪ ⋯│  HUD 品牌行
│ ●你 ¥15,000  ○顾老板 ... │  玩家条（横向滚动）
├──────────────────────────┤
│  ┌────────────────────┐  │
│  │ 24 格环形棋盘 1:1  │  │  --u = 棋盘边长/100
│  │   中心：日辉铜盘   │  │  骰子 + 回合 + 地契印章
│  │   骰子 + 印章      │  │
│  └────────────────────┘  │
├──────────────────────────┤
│ 战报滚动一行             │
├──────────────────────────┤
│ [资产]  [ 掷骰子 ]  [规则]│  操作坞 ≥56px
└──────────────────────────┘
```

- 棋盘 `aspect-ratio: 1`，边长 = `min(可用宽, 视口高 − 固定件预算, 640px)`，由 `ResizeObserver` 写入 `--u`（棋盘边长 / 100）；格内字号、棋子、间距全部用 `calc(var(--u) * N)`，因此任何尺寸都不会横滚。
- 竖屏网格行：`auto auto auto minmax(0,1fr) auto`（顶栏 / 玩家条 / 棋盘 / 战报 / 操作坞）。棋盘按内容高度占位，多出来的竖向空间全部给战报面板，桌面级大屏也不会出现大片空白。
- 桌面 ≥900px：容器居中，棋盘上限 640px，HUD/操作坞拉宽。
- 横屏矮屏（`orientation: landscape and max-height: 520px`）：两栏，棋盘在左，HUD/战报/操作坞在右。
- 底部 sheet 承载：地契/买地决策、拍卖、筹款、资产总览、战报、规则、设置、结算。sheet 支持下滑关闭、Esc 关闭、焦点回收。

## 5. 规则清单

掷单骰 · 逐格移动 · 买地/放弃转拍卖 · 租金 · 满组双倍 · 升级/建房（满组且组内无抵押，差价 ≤1）· 卖房（半价）· 抵押（半价）/赎回（110%）· 机会/命运卡组各 12 张 · 监狱（保释 ¥500 / 出狱许可证 / 掷 6，3 回合强制保释）· 所得税 · 免费停车罚款池 · 破产清算与资产转移 · 排名结算 · AI 对手 · 拍卖 · 资产总览 · 本地存档 · 音效与震动 · 减少动效。

## 6. 代码结构

```
index.html          结构 + SVG 图标 sprite
styles.css          设计系统 + 响应式
js/data.js          棋盘/卡组/配置/坐标映射
js/audio.js         WebAudio 合成音效
js/engine.js        规则引擎（异步回合循环 + 事件）
js/ui.js            渲染、动画、弹层
js/main.js          启动与存档恢复
```

引擎与 UI 通过事件解耦：`state / log / dice / move / ask* / over`。引擎持有异步回合循环，人类决策以 Promise 挂起，AI 决策带延迟。

## 7. 验收

- 390×844 竖屏无横向滚动，按钮 ≥44px，安全区不被遮挡。
- 360×640、844×390 横屏、1280×900 桌面均可用。
- 一局 4 人能从开局走到结算，含买地、建房、租金、机会卡、监狱、破产。
- `prefers-reduced-motion` 下动画退化为即时；键盘可完成掷骰与弹层操作。
